# Summer Bootcamp Project: Uber Ride Data Analysis

## Project Objective
The objective of this project is to perform an in-depth analysis of Uber ride data across various boroughs of New York City to uncover patterns, trends, and correlations that can inform strategic decisions for optimizing Uber operations.

## Dataset
- Uber ride data across multiple boroughs of New York City.
- Includes ride times, locations, and frequency of trips.

## Technologies Used
- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Workflow
1. **Data Collection & Loading**: Load Uber ride dataset into Python using Pandas.
2. **Data Cleaning**: Handle missing values and remove inconsistencies.
3. **Exploratory Data Analysis (EDA)**:
   - Analyze ride frequency across boroughs
   - Study peak hours and trends
   - Identify correlations between rides and time/day
4. **Visualization**: Create plots and graphs to represent patterns and trends.
5. **Insights & Recommendations**: Draw actionable insights to optimize Uber operations.

## Files
- `Final Uber Data Analysis( with codes).ipynb` – Complete analysis with code
- `Uber Data Analysis Report.ipynb` – Report version with visualizations and findings
